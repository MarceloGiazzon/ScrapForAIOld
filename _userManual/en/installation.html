Installation & setup

Two supported ways to run ScrapForAI: Docker Compose for normal use, or local Node.js for development. Configuration is environment-variable driven in both cases.

Prerequisites

Recommended runtime:

  • Docker Desktop.
  • Doppler CLI for secret management.
  • Node.js LTS for local development outside Docker.
  • npm.

Optional:

  • Cloudflare cloudflared, if you want a temporary development tunnel. The Docker Compose file can run cloudflared for you through the tunnel profile.

Option 1: Docker Compose installation

Recommended for normal use.

  1. Open PowerShell.
  2. Go to the project folder: 
    Set-Location -Path "D:\WorkSpace\ScrapForAI"
  3. Install and configure Doppler: 
    doppler login
doppler setup
  4. Build and start the API: 
    doppler run -- docker compose up --build
  5. Verify health: 
    Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Expected response:

{
  "status": "ok",
  "service": "ScrapForAI",
  "time": "2026-06-12T00:00:00.000Z"
}

Option 2: Local Node.js installation

Useful for development.

  1. Open PowerShell.
  2. Go to the project folder: 
    Set-Location -Path "D:\WorkSpace\ScrapForAI"
  3. Install dependencies: 
    npm ci
  4. Create a local .env file from .env.example and edit values: 
    Copy-Item .env.example .env
  5. Install Playwright browser dependencies if needed: 
    npx playwright install
  6. Start the development server: 
    npm run dev
  7. In another PowerShell window, verify health: 
    Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Configuration

ScrapForAI reads configuration from environment variables. In Docker Compose, these are passed to the container. In local development, .env is loaded by the application.

Required variables

VariableRequiredExamplePurpose
SCRAPFORAI_API_KEYYesuse-a-long-random-secretBearer token required for protected endpoints. Must be at least 16 characters.
ALLOWED_TARGET_ORIGINSYeshttps://dev.example.com,https://qa.example.comOrigins ScrapForAI may visit as target URLs and main-frame redirects. Must contain at least one origin.

Common server variables

VariableDefaultPurpose
NODE_ENVdevelopmentRuntime mode: development, test, or production.
PORT3000HTTP port inside the app/container.
HOST0.0.0.0Network interface to bind.
LOG_LEVELinfoPino log level.
MAX_REQUEST_BODY_SIZE1mbMaximum JSON request size accepted by Express.
CORS_ALLOWED_ORIGINSempty listBrowser origins allowed by CORS. Non-browser clients are not affected.

Browser and job limits

VariableDefaultPurpose
PLAYWRIGHT_BROWSERchromiumBrowser engine: chromium, firefox, or webkit.
MAX_STEPS_PER_JOB50Maximum steps in one routine.
MAX_PARALLEL_JOBS2Maximum concurrent exploration or inspection jobs.
JOB_TIMEOUT_MS60000Overall timeout for a routine.
STEP_TIMEOUT_MS10000Maximum timeout for most step actions.
MAX_DOM_SNAPSHOT_CHARS20000Maximum DOM text or rendered HTML snapshot length.

Evaluate and watch limits

VariableDefaultPurpose
ALLOW_EVALUATEfalseEnables evaluate and watch steps when true.
MAX_EVALUATE_SCRIPT_CHARS4000Maximum JavaScript script length.
MAX_EVALUATE_RESULT_CHARS20000Maximum serialized result length before truncation.
EVALUATE_TIMEOUT_MS5000Timeout for one script evaluation.
MAX_WATCH_DURATION_MS30000Maximum watch duration.
MIN_WATCH_INTERVAL_MS100Minimum watch sampling interval.
MAX_WATCH_SAMPLES200Maximum watch samples.

Artifact variables

VariableDefaultPurpose
ARTIFACT_DIR/app/artifactsDirectory where job artifacts are saved. In Compose this maps to ./artifacts.
ARTIFACT_RETENTION_HOURS4Artifact folders older than this are pruned when new jobs create an artifact store.

Example .env

NODE_ENV=development
PORT=3000
HOST=0.0.0.0

SCRAPFORAI_API_KEY=replace-with-a-strong-random-value

ALLOWED_TARGET_ORIGINS=https://dev.example.com,https://qa.example.com
ALLOWED_RESOURCE_ORIGINS=https://dev.example.com,https://qa.example.com,https://api-dev.example.com
CORS_ALLOWED_ORIGINS=http://localhost:3000

MAX_STEPS_PER_JOB=50
JOB_TIMEOUT_MS=60000
STEP_TIMEOUT_MS=10000
MAX_REQUEST_BODY_SIZE=1mb
MAX_PARALLEL_JOBS=2
MAX_DOM_SNAPSHOT_CHARS=20000

ALLOW_EVALUATE=false
MAX_EVALUATE_SCRIPT_CHARS=4000
MAX_EVALUATE_RESULT_CHARS=20000
EVALUATE_TIMEOUT_MS=5000
MAX_WATCH_DURATION_MS=30000
MIN_WATCH_INTERVAL_MS=100
MAX_WATCH_SAMPLES=200

ARTIFACT_RETENTION_HOURS=4
ARTIFACT_DIR=/app/artifacts
LOG_LEVEL=info
PLAYWRIGHT_BROWSER=chromium

Running ScrapForAI

Start with Docker Compose

Set-Location -Path "D:\WorkSpace\ScrapForAI"
doppler run -- docker compose up --build

The Compose file binds the API to http://localhost:3000. The host mapping is restricted to 127.0.0.1:3000:3000, so the service is exposed locally by default.

Start for local development

Set-Location -Path "D:\WorkSpace\ScrapForAI"
npm run dev

Start compiled production code locally

Set-Location -Path "D:\WorkSpace\ScrapForAI"
npm run build
npm start

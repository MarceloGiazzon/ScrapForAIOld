Routine request guide

The full shape of an exploration routine: top-level fields, options, step fields, frame targeting, wait conditions, and value sources.

Minimal routine

{
  "targetUrl": "https://dev.example.com",
  "steps": [
    {
      "action": "goto",
      "url": "$targetUrl"
    }
  ]
}

Full routine structure

{
  "scenarioName": "login smoke test",
  "targetUrl": "https://dev.example.com/login",
  "credentials": {
    "loginUser": "test-user",
    "loginPassword": "test-password"
  },
  "variables": {
    "expectedText": "Dashboard"
  },
  "caller": {
    "correlationId": "ticket-1234",
    "source": "local-ai-tool",
    "metadata": {
      "branch": "feature/login-fix"
    }
  },
  "options": {
    "headless": true,
    "trace": false,
    "screenshots": "onFailure",
    "collectDomOnFailure": true
  },
  "steps": [
    {
      "label": "open login",
      "action": "goto",
      "url": "$targetUrl"
    }
  ]
}

Top-level fields

FieldRequiredDescription
scenarioNameNoHuman-readable routine name, up to 160 characters.
targetUrlYesInitial target URL. Must match ALLOWED_TARGET_ORIGINS.
credentialsNoSecret values used by steps. Values are redacted from results.
variablesNoNon-secret reusable values used by steps.
callerNoOptional metadata about the caller.
optionsNoRuntime options. Defaults are applied when omitted.
stepsYesOrdered list of actions and assertions.

Options

OptionDefaultDescription
headlesstrueRuns browser without UI when true.
tracefalseSaves a Playwright trace ZIP when true.
screenshotsonFailureoff, onFailure, or always.
collectDomOnFailurefalseCaptures DOM text when a step fails.
viewport{ width: 1366, height: 768 }Browser viewport size at job start, e.g. { "width": 390, "height": 844 } for a mobile-sized run. Width/height accept 50–4096 px.
Responsive checks

To test multiple screen sizes inside one job, set options.viewport for the starting size and use the setViewportSize step (see step actions) to resize mid-run.

Common step fields

Every step can include these optional fields:

FieldDescription
idUnique step ID. Required if another step uses waitForElapsed with this step.
labelShort human-readable label.
descriptionLonger description.
frameTargets an iframe by name, URL fragment, or index.
delayMsWaits before the step action.
waitForWait condition executed before the action.
afterWaitForWait condition executed after the action. Response waits are armed before the action.

Frame targeting

Use frame when the control is inside an iframe.

By frame name:

{
  "action": "click",
  "frame": { "name": "payment-frame" },
  "selector": "button[type='submit']"
}

By frame URL fragment:

{
  "action": "fill",
  "frame": { "urlContains": "/embedded/search" },
  "selector": "[name='q']",
  "value": "ABC123"
}

By frame index:

{
  "action": "assertVisible",
  "frame": { "index": 1 },
  "selector": ".loaded"
}

If the frame is not found, ScrapForAI falls back to the main frame.

Wait conditions

waitFor and afterWaitFor support exactly one condition: selector, response, loadState, or urlContains.

Selector wait:

{
  "action": "click",
  "selector": "#open-menu",
  "afterWaitFor": {
    "selector": ".menu-item",
    "state": "visible",
    "timeoutMs": 5000
  }
}

Response wait:

{
  "action": "click",
  "selector": "button[type='submit']",
  "afterWaitFor": {
    "response": {
      "urlContains": "/api/login",
      "status": 200
    },
    "timeoutMs": 10000
  }
}

Load state wait:

{
  "action": "goto",
  "url": "$targetUrl",
  "afterWaitFor": {
    "loadState": "networkidle",
    "timeoutMs": 10000
  }
}

URL wait:

{
  "action": "click",
  "selector": "a[href='/dashboard']",
  "afterWaitFor": {
    "urlContains": "/dashboard",
    "timeoutMs": 10000
  }
}
Tip

Use afterWaitFor.response for responses triggered by the action, because ScrapForAI arms the listener before it performs the action.

Value sources

Some steps need a value, such as fill and selectOption. Exactly one value source is required: value, valueFromCredential, or valueFromVariable.

Literal value:

{
  "action": "fill",
  "selector": "[name='search']",
  "value": "ABC123"
}

Credential value:

{
  "action": "fill",
  "selector": "#password",
  "valueFromCredential": "loginPassword"
}

Variable value:

{
  "action": "fill",
  "selector": "[name='query']",
  "valueFromVariable": "searchText"
}

Glossary

Quick reference for the terms used throughout this manual.

Terms

TermMeaning
ArtifactFile produced by a job, such as result.json, screenshot PNG, or trace ZIP.
CredentialSecret input value supplied under credentials; redacted from output.
DOM inspectionEndpoint that returns forms, controls, selectors, text, and optional diagnostics for a page.
EvidenceStructured diagnostic data collected during a run.
ExplorationA browser automation job run from a routine.
OriginScheme, host, and optional port, such as https://dev.example.com.
RoutineJSON request containing target, options, and ordered steps.
StepOne browser action, wait, assertion, extraction, screenshot, or collection operation.
VariableNon-secret reusable input value supplied under variables.

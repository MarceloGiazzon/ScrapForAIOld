Referencia de acciones de paso

Todas las acciones de paso admitidas, qué hacen, sus campos clave, y el uso detallado de las acciones con estructura adicional.

Acciones admitidas

AcciónPropósitoCampos clave
gotoNavega a $targetUrl o a una URL literal permitida.url, timeoutMs
reloadRecarga la página actual.timeoutMs
waitForLoadStateEspera a domcontentloaded, load o networkidle.state, timeoutMs
waitForUrlContainsEspera hasta que la URL actual contenga el texto.value, timeoutMs
waitForTimeoutEspera un tiempo fijo.timeoutMs
fillCompleta un control de tipo input.selector, una fuente de valor
clickHace clic en un elemento.selector, timeoutMs
doubleClickHace doble clic en un elemento.selector, timeoutMs
hoverPasa el cursor sobre un elemento.selector, timeoutMs
pressPresiona una tecla en un elemento.selector, key, timeoutMs
selectOptionSelecciona un valor de opción.selector, una fuente de valor
checkMarca una casilla o radio.selector, timeoutMs
uncheckDesmarca una casilla.selector, timeoutMs
waitForSelectorEspera el estado de un selector.selector, state, timeoutMs
waitForResponseEspera una respuesta de red.urlContains, method, status, timeoutMs
assertVisibleFalla a menos que el selector esté visible.selector, timeoutMs
assertHiddenFalla a menos que el selector esté oculto.selector, timeoutMs
assertEnabledFalla a menos que el selector esté habilitado.selector, timeoutMs
assertDisabledFalla a menos que el selector esté deshabilitado.selector, timeoutMs
assertTextContainsFalla a menos que el texto del selector contenga el texto esperado.selector, text, timeoutMs
assertUrlContainsFalla a menos que la URL actual contenga el texto.value
assertCountFalla a menos que el conteo del selector cumpla la condición.selector, operator, count
screenshotGuarda una captura de pantalla con nombre.name
collectRecopila la evidencia seleccionada.what
extractTextGuarda el texto interno del selector en extracted.selector, name, timeoutMs
extractAttributeGuarda un atributo en extracted.selector, attribute, name, timeoutMs

Acción collect

collect.what puede incluir: console, network, domText, url, pageErrors.

{
  "action": "collect",
  "what": ["console", "network", "domText", "url", "pageErrors"]
}

Los recolectores de consola, red y errores de página se registran para el trabajo. El paso collect controla principalmente snapshots adicionales, como el texto del DOM y la URL final.

Operadores de aserción

assertCount admite: =, !=, >, >=, <, <=.

{
  "action": "assertCount",
  "selector": "[data-row]",
  "operator": ">=",
  "count": 1
}

waitForElapsed

Usa waitForElapsed cuando la aplicación requiere un intervalo mínimo de tiempo entre acciones.

[
  {
    "id": "clicked-send",
    "action": "click",
    "selector": "#send-code"
  },
  {
    "action": "waitForElapsed",
    "sinceStepId": "clicked-send",
    "minElapsedMs": 3000,
    "timeoutMs": 5000
  },
  {
    "action": "click",
    "selector": "#resend-code"
  }
]

sinceStepId debe referenciar un ID de paso anterior.

setViewportSize

Usa setViewportSize para redimensionar el navegador durante la ejecución — por ejemplo, para verificar un diseño responsivo después de comenzar en tamaño de escritorio. options.viewport (ver opciones de rutina) controla el tamaño al iniciar el trabajo; este paso lo cambia para los pasos posteriores.

[
  {
    "action": "goto",
    "url": "$targetUrl"
  },
  {
    "action": "screenshot",
    "name": "desktop"
  },
  {
    "action": "setViewportSize",
    "width": 390,
    "height": 844
  },
  {
    "action": "screenshot",
    "name": "mobile"
  }
]

El ancho y el alto admiten cada uno entre 50 y 4096 píxeles.

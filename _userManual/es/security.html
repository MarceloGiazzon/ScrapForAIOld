Conceptos y seguridad

Modelo de seguridad

La seguridad es central en ScrapForAI. Configúrala con cuidado antes de conectar cualquier herramienta de IA a la API.

Endpoints públicos

Estos endpoints no requieren autenticación de API:

  • GET /health público
  • GET /v1/schema público
  • GET /v1/schema/routine.request.json público
  • GET /v1/schema/routine.result.json público

Endpoints protegidos

Estos endpoints requieren un token bearer:

Authorization: Bearer <SCRAPFORAI_API_KEY>
  • POST /v1/explorations/run requiere autenticación
  • POST /v1/explorations/inspect-dom requiere autenticación

Restricciones de origen de destino

ALLOWED_TARGET_ORIGINS controla:

  • La targetUrl inicial.
  • Las URLs literales usadas por los pasos goto.
  • Las redirecciones del frame principal.

Solo se permiten los orígenes de esta lista. Si un destino o redirección no está permitido, la solicitud falla.

ALLOWED_TARGET_ORIGINS=https://dev.example.com,https://qa.example.com

El origen incluye esquema, host y puerto opcional. Las rutas se ignoran cuando el servicio normaliza el origen.

Reporte de origen de recursos

ALLOWED_RESOURCE_ORIGINS controla los recursos externos u orígenes de API esperados. Los orígenes de recursos externos inesperados se reportan en la evidencia para que quien llama pueda inspeccionar tráfico externo sospechoso o accidental.

ALLOWED_RESOURCE_ORIGINS=https://dev.example.com,https://api-dev.example.com

Ocultamiento de secretos

ScrapForAI oculta:

  • El SCRAPFORAI_API_KEY configurado.
  • Los valores proporcionados en credentials.
  • Claves y valores sensibles detectados recursivamente en las estructuras de resultado.
  • Los encabezados de autorización y cookies en los logs.
Credentials vs. variables

Las variables de una rutina no se tratan como secretos por defecto. Coloca contraseñas, tokens y otros valores sensibles en credentials, no en variables.

Ejecución de JavaScript

Los pasos evaluate y watch ejecutan JavaScript proporcionado por quien llama dentro de la página. Están deshabilitados de forma predeterminada.

Mantén esta configuración deshabilitada a menos que se cumplan todas estas condiciones:

  • Quien llama es de confianza.
  • El destino es un sistema de desarrollo o prueba controlado.
  • Los datos en el navegador son seguros para uso de diagnóstico local.
  • Entiendes que los scripts pueden leer y modificar el estado de la página.

Habilítalo solo para uso local de confianza:

ALLOW_EVALUATE=true

Los artefactos pueden contener datos sensibles

Las capturas de pantalla, trazas, snapshots de texto del DOM, HTML renderizado y evidencia de red pueden exponer datos de la aplicación. Almacena los artefactos localmente, mantén una retención corta y evita datos de producción.

La retención predeterminada es de 4 horas:

ARTIFACT_RETENTION_HOURS=4

Lista de verificación operativa

Antes de conectar una herramienta de IA

  • Establece un SCRAPFORAI_API_KEY fuerte.
  • Mantén ALLOWED_TARGET_ORIGINS acotado.
  • Mantén ALLOWED_RESOURCE_ORIGINS explícito.
  • Mantén ALLOW_EVALUATE=false a menos que las pruebas locales de confianza lo requieran.
  • Usa credenciales de prueba descartables.
  • Mantén la retención de artefactos corta.
  • Verifica el rechazo de autenticación, el rechazo de la lista de permitidos de URL y el rechazo de JSON inválido.
  • Confirma que los artefactos se escriben solo donde se espera.
  • Evita datos de producción.

Antes de abrir un túnel

  • Confirma que la verificación de salud local funciona.
  • Confirma que los endpoints protegidos requieren la clave de API.
  • Confirma el comportamiento de la lista de permitidos.
  • Confirma que no se usan credenciales de producción.
  • Detén el túnel inmediatamente después de las pruebas.

Antes de compartir artefactos

  • Revisa las capturas de pantalla.
  • Revisa el result.json.
  • Revisa el contenido de la traza.
  • Confirma que las credenciales y tokens están ocultos.
  • Elimina artefactos innecesarios.

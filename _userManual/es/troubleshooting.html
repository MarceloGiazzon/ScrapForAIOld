Solución de problemas

Modos de fallo comunes y cómo diagnosticarlos, desde fallos en el chequeo de salud hasta esperas de respuesta con comportamiento inesperado.

El endpoint de salud falla

Verifica:

  • ¿El contenedor o el servidor de desarrollo está en ejecución?
  • ¿El puerto 3000 ya está en uso?
  • ¿Falló la validación del entorno durante el arranque?
  • ¿Están disponibles Docker Desktop y la imagen de Playwright?
docker logs scrapforai-api
docker compose ps

El endpoint protegido devuelve 401

Verifica:

  • El encabezado está presente.
  • El formato del encabezado es exactamente Authorization: Bearer <clave>.
  • La clave de API coincide con SCRAPFORAI_API_KEY.
  • La clave de API tiene al menos 16 caracteres.
$Headers = @{ Authorization = "Bearer $ApiKey" }

La solicitud devuelve 400 ValidationError

Verifica:

  • El cuerpo JSON es válido.
  • Existen los campos requeridos.
  • targetUrl es una URL válida.
  • Los nombres de las acciones de paso están escritos correctamente.
  • steps no está vacío y no excede MAX_STEPS_PER_JOB.
  • Los pasos basados en valor incluyen exactamente uno de value, valueFromCredential o valueFromVariable.
  • Las condiciones de espera incluyen exactamente una condición.

La respuesta incluye detalles:

{
  "error": {
    "type": "ValidationError",
    "message": "Invalid exploration request",
    "details": [
      {
        "path": "steps.0.selector",
        "message": "Invalid input"
      }
    ]
  }
}

La URL es rechazada

Verifica:

  • El origen de la URL está listado en ALLOWED_TARGET_ORIGINS.
  • El esquema coincide. http:// y https:// son orígenes diferentes.
  • El puerto coincide. http://localhost:3000 y http://localhost:5173 son orígenes diferentes.
  • Las redirecciones permanecen en orígenes permitidos.
ALLOWED_TARGET_ORIGINS=http://localhost:5173,https://dev.example.com

La rutina devuelve 429 TooManyRequests

El número de trabajos activos alcanzó MAX_PARALLEL_JOBS.

Opciones de solución:

  • Espera a que terminen los trabajos actuales.
  • Aumenta MAX_PARALLEL_JOBS.
  • Reduce la duración del trabajo.
  • Reduce la concurrencia del cliente.

El paso agota el tiempo de espera

Verifica:

  • El selector es correcto.
  • El elemento está dentro de un iframe y necesita frame.
  • La página todavía está cargando.
  • La aplicación necesita un waitFor o afterWaitFor más preciso.
  • STEP_TIMEOUT_MS es demasiado bajo para el entorno.

Usa la inspección del DOM para encontrar selectores y una captura de pantalla de fallo para ver el estado de la página.

waitForResponse no detecta una respuesta

Usa afterWaitFor.response en la acción que dispara la respuesta:

{
  "action": "click",
  "selector": "#submit",
  "afterWaitFor": {
    "response": {
      "urlContains": "/api/save",
      "status": 200
    },
    "timeoutMs": 10000
  }
}

Esto arma el listener de respuesta antes del clic.

evaluate o watch es rechazado

Verifica:

ALLOW_EVALUATE=true

Verifica también:

  • La longitud del script está por debajo de MAX_EVALUATE_SCRIPT_CHARS.
  • El script devuelve valores seguros para JSON.
  • El script se completa antes de EVALUATE_TIMEOUT_MS.

Faltan capturas de pantalla

Verifica:

  • options.screenshots no es off.
  • Un paso screenshot tiene un name válido.
  • El trabajo llegó al paso de captura de pantalla.
  • El directorio de artefactos tiene permisos de escritura.

Falta la traza

Verifica:

  • options.trace es true.
  • El trabajo inició Playwright correctamente.
  • El directorio de artefactos tiene permisos de escritura.
  • El resultado incluye evidence.tracePath.

Solicitudes externas inesperadas

Si unexpectedExternalRequests contiene elementos:

  • Confirma si la aplicación llama legítimamente a esos orígenes.
  • Agrega los orígenes esperados a ALLOWED_RESOURCE_ORIGINS.
  • Investiga llamadas inesperadas de terceros en desarrollo o QA.

La inspección del DOM devuelve sensitiveOutput true

Esto ocurre cuando includeRenderedHtml es verdadero. Trata la respuesta como sensible. Prefiere mantener includeRenderedHtml en falso a menos que realmente necesites el HTML.

Guía de solicitudes de rutina

La forma completa de una rutina de exploración: campos de nivel superior, opciones, campos de paso, segmentación de frames, condiciones de espera y fuentes de valor.

Rutina mínima

{
  "targetUrl": "https://dev.example.com",
  "steps": [
    {
      "action": "goto",
      "url": "$targetUrl"
    }
  ]
}

Estructura completa de la rutina

{
  "scenarioName": "login smoke test",
  "targetUrl": "https://dev.example.com/login",
  "credentials": {
    "loginUser": "test-user",
    "loginPassword": "test-password"
  },
  "variables": {
    "expectedText": "Dashboard"
  },
  "caller": {
    "correlationId": "ticket-1234",
    "source": "local-ai-tool",
    "metadata": {
      "branch": "feature/login-fix"
    }
  },
  "options": {
    "headless": true,
    "trace": false,
    "screenshots": "onFailure",
    "collectDomOnFailure": true
  },
  "steps": [
    {
      "label": "open login",
      "action": "goto",
      "url": "$targetUrl"
    }
  ]
}

Campos de nivel superior

CampoRequeridoDescripción
scenarioNameNoNombre legible de la rutina, hasta 160 caracteres.
targetUrlSíURL de destino inicial. Debe coincidir con ALLOWED_TARGET_ORIGINS.
credentialsNoValores secretos usados por los pasos. Los valores se ocultan en los resultados.
variablesNoValores reutilizables no secretos usados por los pasos.
callerNoMetadatos opcionales sobre quien llama.
optionsNoOpciones de ejecución. Se aplican valores predeterminados cuando se omiten.
stepsSíLista ordenada de acciones y aserciones.

Opciones

OpciónPredeterminadoDescripción
headlesstrueEjecuta el navegador sin interfaz cuando es verdadero.
tracefalseGuarda un ZIP de traza de Playwright cuando es verdadero.
screenshotsonFailureoff, onFailure o always.
collectDomOnFailurefalseCaptura el texto del DOM cuando un paso falla.
viewport{ width: 1366, height: 768 }Tamaño del viewport del navegador al iniciar el trabajo, p. ej. { "width": 390, "height": 844 } para una ejecución de tamaño móvil. Ancho/alto aceptan 50–4096 px.
Verificaciones responsivas

Para probar varios tamaños de pantalla dentro de un mismo trabajo, configura options.viewport para el tamaño inicial y usa el paso setViewportSize (ver acciones de paso) para redimensionar durante la ejecución.

Campos comunes de paso

Todo paso puede incluir estos campos opcionales:

CampoDescripción
idID único del paso. Requerido si otro paso usa waitForElapsed referenciando este paso.
labelEtiqueta corta y legible.
descriptionDescripción más larga.
frameApunta a un iframe por nombre, fragmento de URL o índice.
delayMsEspera antes de la acción del paso.
waitForCondición de espera ejecutada antes de la acción.
afterWaitForCondición de espera ejecutada después de la acción. Las esperas de respuesta se arman antes de la acción.

Segmentación de frames

Usa frame cuando el control está dentro de un iframe.

Por nombre de frame:

{
  "action": "click",
  "frame": { "name": "payment-frame" },
  "selector": "button[type='submit']"
}

Por fragmento de URL del frame:

{
  "action": "fill",
  "frame": { "urlContains": "/embedded/search" },
  "selector": "[name='q']",
  "value": "ABC123"
}

Por índice de frame:

{
  "action": "assertVisible",
  "frame": { "index": 1 },
  "selector": ".loaded"
}

Si no se encuentra el frame, ScrapForAI recurre al frame principal.

Condiciones de espera

waitFor y afterWaitFor admiten exactamente una condición: selector, response, loadState o urlContains.

Espera por selector:

{
  "action": "click",
  "selector": "#open-menu",
  "afterWaitFor": {
    "selector": ".menu-item",
    "state": "visible",
    "timeoutMs": 5000
  }
}

Espera por respuesta:

{
  "action": "click",
  "selector": "button[type='submit']",
  "afterWaitFor": {
    "response": {
      "urlContains": "/api/login",
      "status": 200
    },
    "timeoutMs": 10000
  }
}

Espera por estado de carga:

{
  "action": "goto",
  "url": "$targetUrl",
  "afterWaitFor": {
    "loadState": "networkidle",
    "timeoutMs": 10000
  }
}

Espera por URL:

{
  "action": "click",
  "selector": "a[href='/dashboard']",
  "afterWaitFor": {
    "urlContains": "/dashboard",
    "timeoutMs": 10000
  }
}
Consejo

Usa afterWaitFor.response para respuestas disparadas por la acción, porque ScrapForAI arma el listener antes de realizar la acción.

Fuentes de valor

Algunos pasos necesitan un valor, como fill y selectOption. Se requiere exactamente una fuente de valor: value, valueFromCredential o valueFromVariable.

Valor literal:

{
  "action": "fill",
  "selector": "[name='search']",
  "value": "ABC123"
}

Valor de credencial:

{
  "action": "fill",
  "selector": "#password",
  "valueFromCredential": "loginPassword"
}

Valor de variable:

{
  "action": "fill",
  "selector": "[name='query']",
  "valueFromVariable": "searchText"
}

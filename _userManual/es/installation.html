Instalación y configuración

Dos formas admitidas de ejecutar ScrapForAI: Docker Compose para uso normal, o Node.js local para desarrollo. La configuración se basa en variables de entorno en ambos casos.

Requisitos previos

Entorno de ejecución recomendado:

  • Docker Desktop.
  • Doppler CLI para gestión de secretos.
  • Node.js LTS para desarrollo local fuera de Docker.
  • npm.

Opcional:

  • Cloudflare cloudflared, si quieres un túnel de desarrollo temporal. El archivo Docker Compose puede ejecutar cloudflared por ti mediante el perfil tunnel.

Opción 1: Instalación con Docker Compose

Recomendado para uso normal.

  1. Abre PowerShell.
  2. Ve a la carpeta del proyecto: 
    Set-Location -Path "D:\WorkSpace\ScrapForAI"
  3. Instala y configura Doppler: 
    doppler login
doppler setup
  4. Compila e inicia la API: 
    doppler run -- docker compose up --build
  5. Verifica el estado del servicio: 
    Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Respuesta esperada:

{
  "status": "ok",
  "service": "ScrapForAI",
  "time": "2026-06-12T00:00:00.000Z"
}

Opción 2: Instalación local con Node.js

Útil para desarrollo.

  1. Abre PowerShell.
  2. Ve a la carpeta del proyecto: 
    Set-Location -Path "D:\WorkSpace\ScrapForAI"
  3. Instala las dependencias: 
    npm ci
  4. Crea un archivo .env local a partir de .env.example y edita los valores: 
    Copy-Item .env.example .env
  5. Instala las dependencias del navegador de Playwright si es necesario: 
    npx playwright install
  6. Inicia el servidor de desarrollo: 
    npm run dev
  7. En otra ventana de PowerShell, verifica el estado del servicio: 
    Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Configuración

ScrapForAI lee la configuración desde variables de entorno. En Docker Compose, estas se pasan al contenedor. En desarrollo local, la aplicación carga el archivo .env.

Variables requeridas

VariableRequeridaEjemploPropósito
SCRAPFORAI_API_KEYSíuse-a-long-random-secretToken bearer requerido para los endpoints protegidos. Debe tener al menos 16 caracteres.
ALLOWED_TARGET_ORIGINSSíhttps://dev.example.com,https://qa.example.comOrígenes que ScrapForAI puede visitar como URLs de destino y redirecciones del frame principal. Debe contener al menos un origen.

Variables comunes del servidor

VariablePredeterminadoPropósito
NODE_ENVdevelopmentModo de ejecución: development, test o production.
PORT3000Puerto HTTP dentro de la app/contenedor.
HOST0.0.0.0Interfaz de red a la que enlazar.
LOG_LEVELinfoNivel de log de Pino.
MAX_REQUEST_BODY_SIZE1mbTamaño máximo de solicitud JSON aceptado por Express.
CORS_ALLOWED_ORIGINSlista vacíaOrígenes de navegador permitidos por CORS. Los clientes que no son navegadores no se ven afectados.

Límites de navegador y trabajos

VariablePredeterminadoPropósito
PLAYWRIGHT_BROWSERchromiumMotor de navegador: chromium, firefox o webkit.
MAX_STEPS_PER_JOB50Número máximo de pasos en una rutina.
MAX_PARALLEL_JOBS2Número máximo de trabajos de exploración o inspección concurrentes.
JOB_TIMEOUT_MS60000Tiempo de espera total de una rutina.
STEP_TIMEOUT_MS10000Tiempo de espera máximo para la mayoría de las acciones de paso.
MAX_DOM_SNAPSHOT_CHARS20000Longitud máxima del snapshot de texto del DOM o HTML renderizado.

Límites de evaluate y watch

VariablePredeterminadoPropósito
ALLOW_EVALUATEfalseHabilita los pasos evaluate y watch cuando es verdadero.
MAX_EVALUATE_SCRIPT_CHARS4000Longitud máxima del script de JavaScript.
MAX_EVALUATE_RESULT_CHARS20000Longitud máxima del resultado serializado antes de truncarse.
EVALUATE_TIMEOUT_MS5000Tiempo de espera para una evaluación de script.
MAX_WATCH_DURATION_MS30000Duración máxima del watch.
MIN_WATCH_INTERVAL_MS100Intervalo mínimo de muestreo del watch.
MAX_WATCH_SAMPLES200Número máximo de muestras del watch.

Variables de artefactos

VariablePredeterminadoPropósito
ARTIFACT_DIR/app/artifactsDirectorio donde se guardan los artefactos del trabajo. En Compose esto se mapea a ./artifacts.
ARTIFACT_RETENTION_HOURS4Las carpetas de artefactos más antiguas que esto se eliminan cuando nuevos trabajos crean un almacén de artefactos.

Ejemplo de .env

NODE_ENV=development
PORT=3000
HOST=0.0.0.0

SCRAPFORAI_API_KEY=replace-with-a-strong-random-value

ALLOWED_TARGET_ORIGINS=https://dev.example.com,https://qa.example.com
ALLOWED_RESOURCE_ORIGINS=https://dev.example.com,https://qa.example.com,https://api-dev.example.com
CORS_ALLOWED_ORIGINS=http://localhost:3000

MAX_STEPS_PER_JOB=50
JOB_TIMEOUT_MS=60000
STEP_TIMEOUT_MS=10000
MAX_REQUEST_BODY_SIZE=1mb
MAX_PARALLEL_JOBS=2
MAX_DOM_SNAPSHOT_CHARS=20000

ALLOW_EVALUATE=false
MAX_EVALUATE_SCRIPT_CHARS=4000
MAX_EVALUATE_RESULT_CHARS=20000
EVALUATE_TIMEOUT_MS=5000
MAX_WATCH_DURATION_MS=30000
MIN_WATCH_INTERVAL_MS=100
MAX_WATCH_SAMPLES=200

ARTIFACT_RETENTION_HOURS=4
ARTIFACT_DIR=/app/artifacts
LOG_LEVEL=info
PLAYWRIGHT_BROWSER=chromium

Ejecutar ScrapForAI

Iniciar con Docker Compose

Set-Location -Path "D:\WorkSpace\ScrapForAI"
doppler run -- docker compose up --build

El archivo Compose vincula la API a http://localhost:3000. El mapeo de host está restringido a 127.0.0.1:3000:3000, por lo que el servicio se expone localmente de forma predeterminada.

Iniciar para desarrollo local

Set-Location -Path "D:\WorkSpace\ScrapForAI"
npm run dev

Iniciar código de producción compilado localmente

Set-Location -Path "D:\WorkSpace\ScrapForAI"
npm run build
npm start

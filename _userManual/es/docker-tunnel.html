Docker y túnel

Cómo se configura el servicio Compose, y cómo ejecutar de forma segura un túnel rápido (Quick Tunnel) de Cloudflare solo para desarrollo.

Servicio Docker

El servicio Compose se llama:

scrapforai-api

Mapea:

127.0.0.1:3000 -> puerto 3000 del contenedor
./artifacts -> /app/artifacts

Iniciar:

doppler run -- docker compose up --build

Detener:

docker compose down

Ver logs:

docker logs scrapforai-api

Túnel rápido de Cloudflare solo para desarrollo

No inicies un túnel hasta que estas verificaciones funcionen localmente:

  • GET /health.
  • Los endpoints protegidos rechazan claves de API faltantes.
  • El rechazo de la lista de permitidos de URL de destino funciona.
  • El rechazo de esquema JSON inválido funciona.

Iniciar la API más el túnel:

doppler run -- docker compose --profile tunnel up --build

Encontrar la URL pública temporal:

docker logs scrapforai-cloudflared-quick-tunnel
Reglas importantes
  • Usa el túnel solo para desarrollo.
  • Mantén la clave de API habilitada.
  • No envíes credenciales de producción a través del túnel.
  • Mantén ALLOWED_TARGET_ORIGINS acotado.
  • Detén el túnel cuando termines.

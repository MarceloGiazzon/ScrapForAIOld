Artefactos y evidencia

Dónde se escribe en disco la salida del trabajo, cómo se controlan las capturas de pantalla y las trazas, y la estructura del objeto de evidencia en los resultados.

Diseño de artefactos

Cada trabajo obtiene su propia carpeta:

artifacts/
  job_<id>/
    result.json
    screenshots/
      failure.png
      custom-name.png
    trace.zip

Comportamiento de las capturas de pantalla

Controlado por options.screenshots:

ValorComportamiento
offNo se guarda ninguna captura de pantalla.
onFailureSe guarda una captura de fallo cuando un paso falla. Los pasos de captura con nombre también se guardan cuando no está en off.
alwaysLas capturas con nombre se guardan, y la captura de fallo se guarda en caso de fallo.

Comportamiento de la traza

{
  "options": {
    "trace": true
  }
}

Cuando está habilitado, ScrapForAI guarda una traza de Playwright en:

artifacts/job_<id>/trace.zip

Archivo de resultado

La respuesta de la API también se guarda en:

artifacts/job_<id>/result.json

Objeto de evidencia

{
  "screenshots": [],
  "tracePath": "artifacts/job_abc123/trace.zip",
  "console": [],
  "consoleErrors": [],
  "pageErrors": [],
  "network": [],
  "networkFailures": [],
  "unexpectedExternalRequests": [],
  "domTextSnapshot": "text...",
  "finalUrl": "https://dev.example.com/dashboard"
}

Forma completa del resultado

El resultado de exploración de nivel superior incluye:

CampoDescripción
jobIdNombre de la carpeta de artefactos.
scenarioNameRepetido desde la solicitud, si se proporcionó.
statuspassed o failed.
startedAt / finishedAt / durationMsTiempos de todo el trabajo.
targetUrl / finalUrlURL solicitada y resultante.
callerMetadatos de quien llama repetidos, o null.
failedStepIndexÍndice del paso que falló, cuando corresponda.
error{ type, message } de alto nivel cuando falla.
stepsArreglo de resultados por paso: index, id, label, action, status, tiempos y error.
extractedMapa de nombres a valores guardados por extractText, extractAttribute, evaluate o watch.
evidenceEl objeto de evidencia descrito arriba.

Retención de artefactos

Las carpetas de artefactos antiguas se eliminan cuando se crea un nuevo almacén de artefactos. El límite se controla con:

ARTIFACT_RETENTION_HOURS=4

Introducción

Resumen general

ScrapForAI es un ejecutor de exploración de navegador centrado en la seguridad para sitios de desarrollo y pruebas controlados. Este manual cubre todo, desde la instalación hasta la API completa de rutinas.

Qué es ScrapForAI

ScrapForAI expone una API HTTP que acepta una rutina JSON restringida, abre un navegador con Playwright, realiza los pasos solicitados, recopila evidencia útil, oculta secretos conocidos y devuelve un resultado estructurado que una herramienta de IA o cliente de automatización puede consumir.

Úsalo cuando necesites que un agente automatizado inspeccione, navegue, valide o recopile evidencia de una aplicación web de forma predecible y controlada.

Abrir y verificar

Abre una URL de desarrollo o QA y verifica su estado.

Completar y enviar

Completa formularios de inicio de sesión con credenciales de prueba descartables y envíalos.

Navegar por la UI

Haz clic en menús, botones, enlaces, pestañas y controles de formulario en secuencia.

Esperar con precisión

Espera cargas de página, selectores, URLs o respuestas de red específicas.

Verificar condiciones

Verifica texto, visibilidad, estado habilitado, conteo de elementos o condiciones de URL.

Capturar evidencia

Toma capturas de pantalla, recopila datos de consola/red y guarda trazas de Playwright.

Extraer datos

Extrae texto o atributos en una respuesta JSON estructurada.

Inspeccionar el DOM

Descubre selectores seguros y estables antes de escribir un escenario.

ScrapForAI está diseñado como una herramienta de exploración acotada para entornos de confianza. Su mayor valor es dar a una herramienta de IA suficiente contexto de navegador para depurar o verificar una aplicación web sin otorgarle capacidad de scraping ilimitada.

Qué no es ScrapForAI

ScrapForAI no es un scraper genérico de la web abierta. No proporciona:

  • Evasión de anti-bot
  • Bypass de CAPTCHA
  • Sesiones de navegador persistentes
  • Bóveda de credenciales
  • Lógica de scraping específica de sitio
  • Ejecución ilimitada de JavaScript
  • Navegación abierta a sitios arbitrarios
  • Garantías de extracción de datos de producción
Por qué esto importa

El servicio restringe intencionalmente los orígenes de destino, los orígenes de recursos, la estructura de la solicitud, los tiempos de espera, el tamaño de los payloads y los trabajos en paralelo. La configuración predeterminada es conservadora porque las capturas de pantalla, los snapshots del DOM, la evidencia de red, las trazas y los valores extraídos pueden contener información sensible.

Quién debería usar ScrapForAI

ScrapForAI es útil para:

  • Desarrolladores que quieren que un asistente de IA reproduzca errores de UI en entornos locales, de desarrollo o QA.
  • Ingenieros de QA que necesitan comprobaciones de humo repetibles con evidencia estructurada.
  • Ingenieros de plataforma que quieren un ejecutor de navegador pequeño con límites de seguridad explícitos.
  • Creadores de herramientas de IA que necesitan una API controlada para inspección e interacción con aplicaciones web.
  • Ingenieros de soporte que necesitan evidencia reproducible de sistemas de prueba sin otorgar acceso de navegación amplio.

ScrapForAI debe ser usado por personas que entienden la aplicación de destino, la controlan o tienen permiso para probarla, y pueden configurar una lista de permitidos estricta de orígenes de destino.

Evita usar ScrapForAI contra
  • Sitios públicos que no controlas.
  • Sistemas de producción con datos reales de clientes.
  • Aplicaciones cuyos términos prohíben el acceso automatizado.
  • Cualquier sistema donde las capturas de pantalla, trazas o texto del DOM puedan exponer datos sensibles que no puedas almacenar de forma segura.

Conceptos fundamentales

Rutina

Una rutina es la solicitud JSON enviada a POST /v1/explorations/run. Contiene una targetUrl, metadatos opcionales (scenarioName, caller), credentials y variables opcionales, options de ejecución, y una lista ordenada de steps.

Paso (step)

Un paso es una acción o aserción del navegador — por ejemplo goto, fill, click, waitForSelector, assertTextContains, screenshot, collect o extractText. Los pasos se ejecutan en orden. Cuando un paso falla, la rutina se detiene y el resultado se devuelve con status: "failed".

Evidencia

La evidencia es información de diagnóstico recopilada durante la ejecución de la rutina: capturas de pantalla, la ruta de la traza de Playwright, mensajes y errores de consola, errores de página, eventos y fallos de red, solicitudes externas inesperadas, un snapshot de texto del DOM, y la URL final.

Artefacto

Un artefacto es un archivo escrito en el directorio de artefactos configurado: típicamente result.json, screenshots/*.png y trace.zip.

Lista de permitidos

Una lista de permitidos es una lista configurada de orígenes que ScrapForAI tiene permiso para visitar o esperar. La lista principal es ALLOWED_TARGET_ORIGINS, que controla la URL de destino principal, las URLs literales usadas en pasos goto y las redirecciones del frame principal.

Inspección del DOM

La inspección del DOM es un endpoint independiente que abre una página de destino y devuelve formularios, controles, selectores, texto visible y, opcionalmente, datos de consola o red. Úsalo para descubrir selectores estables antes de escribir una rutina.

Resumen de la arquitectura

ScrapForAI es un servicio de Node.js y TypeScript construido sobre:

  • Express para enrutamiento HTTP.
  • Playwright para automatización de navegador.
  • Zod para validación de solicitudes.
  • Pino para registro estructurado.
  • Helmet, CORS, limitación de tasa y autenticación por bearer token para protección de la API.
  • Docker con la imagen oficial de Playwright para un runtime de navegador consistente.

Flujo de alto nivel

  1. Un cliente envía una solicitud JSON a ScrapForAI.
  2. Express autentica la solicitud, salvo que sea GET /health o GET /v1/schema*.
  3. Zod valida la estructura de la solicitud y las reglas entre campos.
  4. La URL de destino se verifica contra ALLOWED_TARGET_ORIGINS.
  5. Playwright abre un contexto de navegador.
  6. Los pasos se ejecutan en orden.
  7. Los recolectores de evidencia registran consola, red, errores de página, capturas de pantalla y datos de traza.
  8. Los secretos conocidos se ocultan de los resultados.
  9. Se devuelve un resultado JSON estructurado, que también se guarda como artefacto.

Primeros pasos

Inicio rápido

Una primera ejecución completa: confirma que el servicio está saludable, autentícate, inspecciona una página de login para encontrar selectores, construye una rutina, ejecútala y lee el resultado.

Supuestos

ScrapForAI se está ejecutando en http://localhost:3000, tu clave de API está configurada, y https://dev.example.com está en ALLOWED_TARGET_ORIGINS.

Paso 1: Confirma que el servicio está activo

Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Deberías recibir status: "ok".

Paso 2: Configura el encabezado de tu clave de API

$ApiKey = "paste-your-scrapforai-api-key-here"
$Headers = @{ Authorization = "Bearer $ApiKey" }

Paso 3: Inspecciona la página de login

$InspectBody = @{
    targetUrl = "https://dev.example.com/login"
    includeHiddenControls = $true
    includeConsole = $true
    includeNetwork = $false
    redactSensitiveValues = $true
} | ConvertTo-Json -Depth 20

$Inspection = Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/inspect-dom" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $InspectBody

$Inspection.visibleControls | Select-Object index, tag, id, name, type, text, labelContext

Usa los valores de selectors devueltos para elegir selectores estables. Consulta la guía de inspección del DOM para más consejos de selección.

Paso 4: Construye una rutina de login

$RunBody = @{
    scenarioName = "first login smoke"
    targetUrl = "https://dev.example.com/login"
    credentials = @{
        loginUser = "test-user"
        loginPassword = "test-password"
    }
    options = @{
        trace = $false
        screenshots = "onFailure"
        collectDomOnFailure = $true
    }
    steps = @(
        @{ label = "open login"; action = "goto"; url = "`$targetUrl" },
        @{ label = "fill user"; action = "fill"; selector = "#username"; valueFromCredential = "loginUser" },
        @{ label = "fill password"; action = "fill"; selector = "#password"; valueFromCredential = "loginPassword" },
        @{
            label = "submit"
            action = "click"
            selector = "button[type='submit']"
            afterWaitFor = @{
                urlContains = "/dashboard"
                timeoutMs = 10000
            }
        },
        @{ label = "assert dashboard"; action = "assertTextContains"; selector = "body"; text = "Dashboard" },
        @{ label = "collect diagnostics"; action = "collect"; what = @("console", "network", "url", "pageErrors") }
    )
} | ConvertTo-Json -Depth 30

Paso 5: Ejecuta la rutina

$Result = Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/run" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $RunBody

$Result.status
$Result.jobId
$Result.evidence.screenshots

Paso 6: Lee el resultado

Campos importantes:

  • status: passed o failed.
  • jobId: nombre de la carpeta de artefactos.
  • failedStepIndex: índice del paso que falló, cuando corresponda.
  • error: error de alto nivel cuando falla.
  • steps: estado y tiempos de cada paso.
  • extracted: valores guardados por los pasos extract/evaluate/watch.
  • evidence: datos de diagnóstico.

Paso 7: Inspecciona los artefactos

Con Docker Compose, los artefactos se escriben en:

D:\WorkSpace\ScrapForAI\artifacts

Para el job job_abc123, inspecciona:

artifacts/job_abc123/result.json
artifacts/job_abc123/screenshots/failure.png
artifacts/job_abc123/trace.zip

La traza solo existe cuando options.trace es verdadero. Consulta Artefactos y evidencia para el diseño completo.

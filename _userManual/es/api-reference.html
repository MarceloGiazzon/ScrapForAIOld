Referencia de la API

Todos los endpoints HTTP expuestos por ScrapForAI, sus requisitos de autenticación, formatos de solicitud y códigos de estado.

Autenticación de la API

Las llamadas protegidas de la API requieren un token bearer.

Configuración del encabezado en PowerShell:

$ApiKey = "paste-your-scrapforai-api-key-here"
$Headers = @{ Authorization = "Bearer $ApiKey" }

Configuración del encabezado con curl:

API_KEY="paste-your-scrapforai-api-key-here"
curl -H "Authorization: Bearer $API_KEY" http://localhost:3000/v1/schema

El endpoint de schema es público, pero usar el mismo estilo de encabezado en todas las llamadas es conveniente.

Comportamiento esperado cuando no está autorizado:

  • Encabezado faltante: 401 Unauthorized.
  • Clave de API incorrecta: 401 Unauthorized.
  • Endpoint protegido sin token bearer: 401 Unauthorized.

POST /v1/explorations/run

POSTrequiere autenticación

Ejecuta una rutina de exploración de navegador.

$Body = @{
    scenarioName = "basic page check"
    targetUrl = "https://dev.example.com"
    options = @{
        trace = $false
        screenshots = "onFailure"
        collectDomOnFailure = $true
    }
    steps = @(
        @{ action = "goto"; url = "`$targetUrl" },
        @{ action = "assertTextContains"; selector = "body"; text = "Welcome" },
        @{ action = "collect"; what = @("console", "network", "url") }
    )
} | ConvertTo-Json -Depth 20

Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/run" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $Body
EstadoSignificado
200La rutina se ejecutó y pasó.
500Una rutina válida se ejecutó pero falló (p. ej. una aserción de paso o un tiempo de espera).
400La solicitud es inválida, o una URL no está permitida.
401La autenticación falló.
429Ya hay demasiados trabajos en ejecución (ver MAX_PARALLEL_JOBS).

POST /v1/explorations/inspect-dom

POSTrequiere autenticación

Inspecciona la página de destino y devuelve controles, formularios, selectores, texto y evidencia de diagnóstico opcional.

$Body = @{
    targetUrl = "https://dev.example.com/login"
    waitUntil = "domcontentloaded"
    includeRenderedHtml = $false
    includeHiddenControls = $true
    includeConsole = $true
    includeNetwork = $false
    redactSensitiveValues = $true
} | ConvertTo-Json -Depth 20

Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/inspect-dom" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $Body

Consulta la guía de inspección del DOM para el formato completo de la respuesta y la referencia de campos.

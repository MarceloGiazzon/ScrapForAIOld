Flujo de desarrollo

Scripts npm comunes usados al trabajar en el propio ScrapForAI: verificación de tipos, build y los conjuntos de pruebas.

Verificación de tipos

npm run typecheck

Build

npm run build

Ejecutar pruebas

npm test

Ejecutar smoke tests

npm run test:smoke

Ejecutar todas las pruebas

npm run test:all

Iniciar el servidor de desarrollo

npm run dev

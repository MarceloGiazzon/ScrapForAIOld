Esquemas JSON

ScrapForAI publica JSON Schemas en vivo para solicitudes y resultados, además de los snapshots de esquema versionados en el repositorio.

Esquemas en vivo

Invoke-RestMethod -Method Get -Uri "http://localhost:3000/v1/schema"
Invoke-RestMethod -Method Get -Uri "http://localhost:3000/v1/schema/routine.request.json"
Invoke-RestMethod -Method Get -Uri "http://localhost:3000/v1/schema/routine.result.json"

Esquemas versionados

schema/routine.request.json
schema/routine.result.json

Para regenerarlos:

npm run generate:schema

El build también regenera los esquemas primero:

npm run build

El esquema en vivo refleja los límites del entorno en ejecución. El esquema versionado refleja los valores predeterminados al momento de la generación.

Reglas de validación entre campos

La validación del lado del servidor también aplica reglas entre campos que no están completamente capturadas por el JSON Schema, entre ellas:

  • IDs de paso únicos.
  • waitForElapsed.sinceStepId debe apuntar a un paso anterior.
  • Exactamente una fuente de valor para los pasos basados en valor.
  • Exactamente una condición de espera en waitFor y afterWaitFor.
  • evaluate y watch requieren ALLOW_EVALUATE=true.

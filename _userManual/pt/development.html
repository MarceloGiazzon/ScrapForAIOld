Fluxo de desenvolvimento

Scripts npm comuns usados ao trabalhar no próprio ScrapForAI: verificação de tipos, build e os conjuntos de testes.

Verificação de tipos

npm run typecheck

Build

npm run build

Executar testes

npm test

Executar smoke tests

npm run test:smoke

Executar todos os testes

npm run test:all

Iniciar o servidor de desenvolvimento

npm run dev

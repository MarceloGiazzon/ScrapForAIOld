Artefatos e evidências

Onde a saída do job é gravada no disco, como screenshots e traces são controlados, e a estrutura do objeto de evidência nos resultados.

Layout de artefatos

Cada job recebe sua própria pasta:

artifacts/
  job_<id>/
    result.json
    screenshots/
      failure.png
      custom-name.png
    trace.zip

Comportamento de screenshots

Controlado por options.screenshots:

ValorComportamento
offNenhum screenshot é salvo.
onFailureO screenshot de falha é salvo quando um passo falha. Passos de screenshot nomeados também salvam quando screenshots não está desligado.
alwaysScreenshots nomeados são salvos, e o screenshot de falha é salvo em caso de falha.

Comportamento de trace

{
  "options": {
    "trace": true
  }
}

Quando habilitado, o ScrapForAI salva um trace do Playwright em:

artifacts/job_<id>/trace.zip

Arquivo de resultado

A resposta da API também é salva em:

artifacts/job_<id>/result.json

Objeto de evidência

{
  "screenshots": [],
  "tracePath": "artifacts/job_abc123/trace.zip",
  "console": [],
  "consoleErrors": [],
  "pageErrors": [],
  "network": [],
  "networkFailures": [],
  "unexpectedExternalRequests": [],
  "domTextSnapshot": "text...",
  "finalUrl": "https://dev.example.com/dashboard"
}

Formato completo do resultado

O resultado de exploração de nível superior inclui:

CampoDescrição
jobIdNome da pasta de artefatos.
scenarioNameRepetido a partir da requisição, se fornecido.
statuspassed ou failed.
startedAt / finishedAt / durationMsTempo de todo o job.
targetUrl / finalUrlURL solicitada e resultante.
callerMetadados do chamador repetidos, ou null.
failedStepIndexÍndice do passo que falhou, quando aplicável.
error{ type, message } de alto nível quando há falha.
stepsArray de resultados por passo: index, id, label, action, status, tempos e error.
extractedMapa de nomes para valores salvos por extractText, extractAttribute, evaluate ou watch.
evidenceO objeto de evidência descrito acima.

Retenção de artefatos

Pastas de artefatos antigas são removidas quando um novo repositório de artefatos é criado. O corte é controlado por:

ARTIFACT_RETENTION_HOURS=4

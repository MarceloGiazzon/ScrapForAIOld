Docker e túnel

Como o serviço Compose é configurado, e como executar com segurança um túnel rápido (Quick Tunnel) da Cloudflare apenas para desenvolvimento.

Serviço Docker

O serviço Compose é chamado:

scrapforai-api

Ele mapeia:

127.0.0.1:3000 -> porta 3000 do container
./artifacts -> /app/artifacts

Iniciar:

doppler run -- docker compose up --build

Parar:

docker compose down

Ver logs:

docker logs scrapforai-api

Túnel rápido da Cloudflare apenas para desenvolvimento

Não inicie um túnel até que estas verificações funcionem localmente:

  • GET /health.
  • Os endpoints protegidos rejeitam chaves de API ausentes.
  • A rejeição da allowlist de URL de destino funciona.
  • A rejeição de schema JSON inválido funciona.

Iniciar a API mais o túnel:

doppler run -- docker compose --profile tunnel up --build

Encontrar a URL pública temporária:

docker logs scrapforai-cloudflared-quick-tunnel
Regras importantes
  • Use o túnel apenas para desenvolvimento.
  • Mantenha a chave de API habilitada.
  • Não envie credenciais de produção através do túnel.
  • Mantenha ALLOWED_TARGET_ORIGINS restrito.
  • Pare o túnel ao terminar.

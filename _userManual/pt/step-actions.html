Referência de ações de passo

Todas as ações de passo suportadas, o que fazem, seus campos principais, e o uso detalhado das ações com estrutura adicional.

Ação collect

collect.what pode incluir: console, network, domText, url, pageErrors.

{
  "action": "collect",
  "what": ["console", "network", "domText", "url", "pageErrors"]
}

Os coletores de console, rede e erros de página são registrados para o job. O passo collect controla principalmente snapshots extras, como texto do DOM e URL final.

Operadores de asserção

assertCount suporta: =, !=, >, >=, <, <=.

{
  "action": "assertCount",
  "selector": "[data-row]",
  "operator": ">=",
  "count": 1
}

waitForElapsed

Use waitForElapsed quando a aplicação exigir um intervalo mínimo de tempo entre ações.

[
  {
    "id": "clicked-send",
    "action": "click",
    "selector": "#send-code"
  },
  {
    "action": "waitForElapsed",
    "sinceStepId": "clicked-send",
    "minElapsedMs": 3000,
    "timeoutMs": 5000
  },
  {
    "action": "click",
    "selector": "#resend-code"
  }
]

O sinceStepId deve referenciar um ID de passo anterior.

setViewportSize

Use setViewportSize para redimensionar o navegador durante a execução — por exemplo, para verificar um layout responsivo após iniciar em tamanho desktop. options.viewport (veja opções da rotina) controla o tamanho no início do job; este passo o altera para os passos subsequentes.

[
  {
    "action": "goto",
    "url": "$targetUrl"
  },
  {
    "action": "screenshot",
    "name": "desktop"
  },
  {
    "action": "setViewportSize",
    "width": 390,
    "height": 844
  },
  {
    "action": "screenshot",
    "name": "mobile"
  }
]

Largura e altura aceitam, cada uma, de 50 a 4096 pixels.

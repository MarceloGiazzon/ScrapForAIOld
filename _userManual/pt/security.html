Conceitos e segurança

Modelo de segurança

A segurança é central para o ScrapForAI. Configure-a com cuidado antes de conectar qualquer ferramenta de IA à API.

Endpoints públicos

Estes endpoints não exigem autenticação de API:

  • GET /health público
  • GET /v1/schema público
  • GET /v1/schema/routine.request.json público
  • GET /v1/schema/routine.result.json público

Endpoints protegidos

Estes endpoints exigem um token bearer:

Authorization: Bearer <SCRAPFORAI_API_KEY>
  • POST /v1/explorations/run requer autenticação
  • POST /v1/explorations/inspect-dom requer autenticação

Restrições de origem de destino

ALLOWED_TARGET_ORIGINS controla:

  • A targetUrl inicial.
  • URLs literais usadas por passos goto.
  • Redirecionamentos do frame principal.

Apenas origens nesta lista são permitidas. Se um destino ou redirecionamento não for permitido, a requisição falha.

ALLOWED_TARGET_ORIGINS=https://dev.example.com,https://qa.example.com

A origem inclui esquema, host e porta opcional. Caminhos são ignorados quando o serviço normaliza a origem.

Relato de origem de recursos

ALLOWED_RESOURCE_ORIGINS controla os recursos externos ou origens de API esperados. Origens de recursos externos inesperadas são relatadas na evidência para que o chamador possa inspecionar tráfego externo suspeito ou acidental.

ALLOWED_RESOURCE_ORIGINS=https://dev.example.com,https://api-dev.example.com

Ocultação de segredos

O ScrapForAI oculta:

  • O SCRAPFORAI_API_KEY configurado.
  • Valores fornecidos em credentials.
  • Chaves e valores sensíveis detectados recursivamente nas estruturas de resultado.
  • Cabeçalhos de autorização e cookies nos logs.
Credentials vs. variables

As variables de uma rotina não são tratadas como segredos por padrão. Coloque senhas, tokens e outros valores sensíveis em credentials, não em variables.

Execução de JavaScript

Os passos evaluate e watch executam JavaScript fornecido pelo chamador dentro da página. Eles estão desabilitados por padrão.

Mantenha essa configuração desabilitada, a menos que todas estas condições sejam verdadeiras:

  • O chamador é confiável.
  • O destino é um sistema de desenvolvimento ou teste controlado.
  • Os dados no navegador são seguros para uso diagnóstico local.
  • Você entende que os scripts podem ler e modificar o estado da página.

Habilite apenas para uso local confiável:

ALLOW_EVALUATE=true

Artefatos podem conter dados sensíveis

Screenshots, traces, snapshots de texto do DOM, HTML renderizado e evidências de rede podem expor dados da aplicação. Armazene os artefatos localmente, mantenha a retenção curta e evite dados de produção.

A retenção padrão é de 4 horas:

ARTIFACT_RETENTION_HOURS=4

Checklist operacional

Antes de conectar uma ferramenta de IA

  • Defina um SCRAPFORAI_API_KEY forte.
  • Mantenha ALLOWED_TARGET_ORIGINS restrito.
  • Mantenha ALLOWED_RESOURCE_ORIGINS explícito.
  • Mantenha ALLOW_EVALUATE=false, a menos que testes locais confiáveis exijam o contrário.
  • Use credenciais de teste descartáveis.
  • Mantenha a retenção de artefatos curta.
  • Verifique a rejeição de autenticação, a rejeição da allowlist de URL e a rejeição de JSON inválido.
  • Confirme que os artefatos são gravados apenas onde esperado.
  • Evite dados de produção.

Antes de abrir um túnel

  • Confirme que a verificação de saúde local funciona.
  • Confirme que os endpoints protegidos exigem a chave de API.
  • Confirme o comportamento da allowlist.
  • Confirme que nenhuma credencial de produção está em uso.
  • Pare o túnel imediatamente após os testes.

Antes de compartilhar artefatos

  • Revise os screenshots.
  • Revise o result.json.
  • Revise o conteúdo do trace.
  • Confirme que credenciais e tokens estão ocultados.
  • Remova artefatos desnecessários.

Introdução

Visão geral

O ScrapForAI é um executor de exploração de navegador com segurança em primeiro lugar, para sites de desenvolvimento e teste controlados. Este manual cobre tudo, desde a instalação até a API completa de rotinas.

O que o ScrapForAI é

O ScrapForAI expõe uma API HTTP que aceita uma rotina JSON restrita, abre um navegador com o Playwright, executa os passos solicitados, coleta evidências úteis, oculta segredos conhecidos e retorna um resultado estruturado que uma ferramenta de IA ou cliente de automação pode consumir.

Use-o quando precisar que um agente automatizado inspecione, navegue, valide ou colete evidências de uma aplicação web de forma previsível e controlada.

Abrir e verificar

Abra uma URL de desenvolvimento ou QA e valide seu estado.

Preencher e enviar

Preencha formulários de login com credenciais de teste descartáveis e envie-os.

Navegar pela UI

Clique em menus, botões, links, abas e controles de formulário em sequência.

Esperar com precisão

Aguarde carregamentos de página, seletores, URLs ou respostas de rede específicas.

Validar condições

Valide texto, visibilidade, estado habilitado, contagem de elementos ou condições de URL.

Capturar evidências

Tire screenshots, colete dados de console/rede e salve traces do Playwright.

Extrair dados

Extraia texto ou atributos em uma resposta JSON estruturada.

Inspecionar o DOM

Descubra seletores seguros e estáveis antes de escrever um cenário.

O ScrapForAI foi projetado como uma ferramenta de exploração limitada para ambientes confiáveis. Seu maior valor é dar a uma ferramenta de IA contexto de navegador suficiente para depurar ou verificar uma aplicação web sem conceder capacidade ilimitada de scraping.

O que o ScrapForAI não é

O ScrapForAI não é um scraper genérico para a web aberta. Ele não oferece:

  • Evasão de anti-bot
  • Contorno de CAPTCHA
  • Sessões de navegador persistentes
  • Cofre de credenciais
  • Lógica de scraping específica de site
  • Execução ilimitada de JavaScript
  • Navegação livre para sites arbitrários
  • Garantias de extração de dados de produção
Por que isso importa

O serviço restringe intencionalmente origens de destino, origens de recursos, estrutura da requisição, timeouts, tamanhos de payload e jobs paralelos. A configuração padrão é conservadora porque screenshots, snapshots de DOM, evidências de rede, traces e valores extraídos podem conter informações sensíveis.

Quem deve usar o ScrapForAI

O ScrapForAI é útil para:

  • Desenvolvedores que querem que um assistente de IA reproduza bugs de UI em ambientes locais, de dev ou QA.
  • Engenheiros de QA que precisam de verificações de smoke test repetíveis com evidências estruturadas.
  • Engenheiros de plataforma que querem um executor de navegador pequeno com limites de segurança explícitos.
  • Criadores de ferramentas de IA que precisam de uma API controlada para inspeção e interação com aplicações web.
  • Engenheiros de suporte que precisam de evidências reproduzíveis de sistemas de teste sem conceder acesso amplo de navegação.

O ScrapForAI deve ser usado por pessoas que entendem a aplicação de destino, controlam ou têm permissão para testá-la, e podem configurar uma allowlist estrita de origens de destino.

Evite usar o ScrapForAI contra
  • Sites públicos que você não controla.
  • Sistemas de produção com dados reais de clientes.
  • Aplicações cujos termos proíbem acesso automatizado.
  • Qualquer sistema em que screenshots, traces ou texto de DOM possam expor dados sensíveis que você não pode armazenar com segurança.

Conceitos fundamentais

Rotina

Uma rotina é a requisição JSON enviada para POST /v1/explorations/run. Ela contém uma targetUrl, metadados opcionais (scenarioName, caller), credentials e variables opcionais, options de execução, e uma lista ordenada de steps.

Passo (step)

Um passo é uma ação ou asserção do navegador — por exemplo goto, fill, click, waitForSelector, assertTextContains, screenshot, collect ou extractText. Os passos executam em ordem. Quando um passo falha, a rotina para e o resultado é retornado com status: "failed".

Evidência

Evidência é o dado de diagnóstico coletado durante a execução da rotina: screenshots, o caminho do trace do Playwright, mensagens e erros de console, erros de página, eventos e falhas de rede, requisições externas inesperadas, um snapshot de texto do DOM, e a URL final.

Artefato

Um artefato é um arquivo gravado no diretório de artefatos configurado: tipicamente result.json, screenshots/*.png e trace.zip.

Allowlist

Uma allowlist é uma lista configurada de origens que o ScrapForAI tem permissão para visitar ou esperar. A allowlist principal é ALLOWED_TARGET_ORIGINS, que controla a URL de destino principal, URLs literais usadas em passos goto e redirecionamentos do frame principal.

Inspeção de DOM

A inspeção de DOM é um endpoint separado que abre uma página de destino e retorna formulários, controles, seletores, texto visível e, opcionalmente, dados de console ou rede. Use-a para descobrir seletores estáveis antes de escrever uma rotina.

Visão geral da arquitetura

O ScrapForAI é um serviço Node.js e TypeScript construído sobre:

  • Express para roteamento HTTP.
  • Playwright para automação de navegador.
  • Zod para validação de requisições.
  • Pino para logging estruturado.
  • Helmet, CORS, rate limiting e autenticação por bearer token para proteção da API.
  • Docker com a imagem oficial do Playwright para um runtime de navegador consistente.

Fluxo de alto nível

  1. Um cliente envia uma requisição JSON ao ScrapForAI.
  2. O Express autentica a requisição, exceto para GET /health ou GET /v1/schema*.
  3. O Zod valida a estrutura da requisição e regras entre campos.
  4. A URL de destino é verificada contra ALLOWED_TARGET_ORIGINS.
  5. O Playwright abre um contexto de navegador.
  6. Os passos são executados em ordem.
  7. Os coletores de evidência registram console, rede, erros de página, screenshots e dados de trace.
  8. Segredos conhecidos são ocultados dos resultados.
  9. Um resultado JSON estruturado é retornado e também salvo como artefato.

Guia da requisição de rotina

A estrutura completa de uma rotina de exploração: campos de nível superior, opções, campos de passo, direcionamento de frame, condições de espera e fontes de valor.

Rotina mínima

{
  "targetUrl": "https://dev.example.com",
  "steps": [
    {
      "action": "goto",
      "url": "$targetUrl"
    }
  ]
}

Estrutura completa da rotina

{
  "scenarioName": "login smoke test",
  "targetUrl": "https://dev.example.com/login",
  "credentials": {
    "loginUser": "test-user",
    "loginPassword": "test-password"
  },
  "variables": {
    "expectedText": "Dashboard"
  },
  "caller": {
    "correlationId": "ticket-1234",
    "source": "local-ai-tool",
    "metadata": {
      "branch": "feature/login-fix"
    }
  },
  "options": {
    "headless": true,
    "trace": false,
    "screenshots": "onFailure",
    "collectDomOnFailure": true
  },
  "steps": [
    {
      "label": "open login",
      "action": "goto",
      "url": "$targetUrl"
    }
  ]
}

Campos de nível superior

CampoObrigatórioDescrição
scenarioNameNãoNome legível da rotina, até 160 caracteres.
targetUrlSimURL de destino inicial. Deve corresponder a ALLOWED_TARGET_ORIGINS.
credentialsNãoValores secretos usados pelos passos. Os valores são ocultados nos resultados.
variablesNãoValores reutilizáveis não secretos usados pelos passos.
callerNãoMetadados opcionais sobre o chamador.
optionsNãoOpções de execução. Padrões são aplicados quando omitidos.
stepsSimLista ordenada de ações e asserções.

Opções

OpçãoPadrãoDescrição
headlesstrueExecuta o navegador sem interface quando verdadeiro.
tracefalseSalva um ZIP de trace do Playwright quando verdadeiro.
screenshotsonFailureoff, onFailure ou always.
collectDomOnFailurefalseCaptura o texto do DOM quando um passo falha.
viewport{ width: 1366, height: 768 }Tamanho do viewport do navegador no início do job, ex. { "width": 390, "height": 844 } para uma execução em tamanho de celular. Largura/altura aceitam 50–4096 px.
Verificações responsivas

Para testar vários tamanhos de tela dentro de um único job, defina options.viewport para o tamanho inicial e use o passo setViewportSize (veja ações de passo) para redimensionar durante a execução.

Campos comuns de passo

Todo passo pode incluir estes campos opcionais:

CampoDescrição
idID único do passo. Obrigatório se outro passo usar waitForElapsed referenciando este passo.
labelRótulo curto e legível.
descriptionDescrição mais longa.
frameDireciona para um iframe por nome, fragmento de URL ou índice.
delayMsEspera antes da ação do passo.
waitForCondição de espera executada antes da ação.
afterWaitForCondição de espera executada após a ação. Esperas de resposta são armadas antes da ação.

Direcionamento de frame

Use frame quando o controle estiver dentro de um iframe.

Por nome do frame:

{
  "action": "click",
  "frame": { "name": "payment-frame" },
  "selector": "button[type='submit']"
}

Por fragmento de URL do frame:

{
  "action": "fill",
  "frame": { "urlContains": "/embedded/search" },
  "selector": "[name='q']",
  "value": "ABC123"
}

Por índice do frame:

{
  "action": "assertVisible",
  "frame": { "index": 1 },
  "selector": ".loaded"
}

Se o frame não for encontrado, o ScrapForAI recorre ao frame principal.

Condições de espera

waitFor e afterWaitFor suportam exatamente uma condição: selector, response, loadState ou urlContains.

Espera por seletor:

{
  "action": "click",
  "selector": "#open-menu",
  "afterWaitFor": {
    "selector": ".menu-item",
    "state": "visible",
    "timeoutMs": 5000
  }
}

Espera por resposta:

{
  "action": "click",
  "selector": "button[type='submit']",
  "afterWaitFor": {
    "response": {
      "urlContains": "/api/login",
      "status": 200
    },
    "timeoutMs": 10000
  }
}

Espera por estado de carregamento:

{
  "action": "goto",
  "url": "$targetUrl",
  "afterWaitFor": {
    "loadState": "networkidle",
    "timeoutMs": 10000
  }
}

Espera por URL:

{
  "action": "click",
  "selector": "a[href='/dashboard']",
  "afterWaitFor": {
    "urlContains": "/dashboard",
    "timeoutMs": 10000
  }
}
Dica

Use afterWaitFor.response para respostas disparadas pela ação, porque o ScrapForAI arma o listener antes de executar a ação.

Fontes de valor

Alguns passos precisam de um valor, como fill e selectOption. É necessário exatamente uma fonte de valor: value, valueFromCredential ou valueFromVariable.

Valor literal:

{
  "action": "fill",
  "selector": "[name='search']",
  "value": "ABC123"
}

Valor de credencial:

{
  "action": "fill",
  "selector": "#password",
  "valueFromCredential": "loginPassword"
}

Valor de variável:

{
  "action": "fill",
  "selector": "[name='query']",
  "valueFromVariable": "searchText"
}

Primeiros passos

Início rápido

Uma primeira execução completa: confirme que o serviço está saudável, autentique-se, inspecione uma página de login em busca de seletores, monte uma rotina, execute-a e leia o resultado.

Pressupostos

O ScrapForAI está em execução em http://localhost:3000, sua chave de API está configurada, e https://dev.example.com está em ALLOWED_TARGET_ORIGINS.

Passo 1: Confirme que o serviço está ativo

Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Você deve receber status: "ok".

Passo 2: Configure o cabeçalho da sua chave de API

$ApiKey = "paste-your-scrapforai-api-key-here"
$Headers = @{ Authorization = "Bearer $ApiKey" }

Passo 3: Inspecione a página de login

$InspectBody = @{
    targetUrl = "https://dev.example.com/login"
    includeHiddenControls = $true
    includeConsole = $true
    includeNetwork = $false
    redactSensitiveValues = $true
} | ConvertTo-Json -Depth 20

$Inspection = Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/inspect-dom" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $InspectBody

$Inspection.visibleControls | Select-Object index, tag, id, name, type, text, labelContext

Use os valores de selectors retornados para escolher seletores estáveis. Veja o guia de inspeção de DOM para dicas de seleção.

Passo 4: Monte uma rotina de login

$RunBody = @{
    scenarioName = "first login smoke"
    targetUrl = "https://dev.example.com/login"
    credentials = @{
        loginUser = "test-user"
        loginPassword = "test-password"
    }
    options = @{
        trace = $false
        screenshots = "onFailure"
        collectDomOnFailure = $true
    }
    steps = @(
        @{ label = "open login"; action = "goto"; url = "`$targetUrl" },
        @{ label = "fill user"; action = "fill"; selector = "#username"; valueFromCredential = "loginUser" },
        @{ label = "fill password"; action = "fill"; selector = "#password"; valueFromCredential = "loginPassword" },
        @{
            label = "submit"
            action = "click"
            selector = "button[type='submit']"
            afterWaitFor = @{
                urlContains = "/dashboard"
                timeoutMs = 10000
            }
        },
        @{ label = "assert dashboard"; action = "assertTextContains"; selector = "body"; text = "Dashboard" },
        @{ label = "collect diagnostics"; action = "collect"; what = @("console", "network", "url", "pageErrors") }
    )
} | ConvertTo-Json -Depth 30

Passo 5: Execute a rotina

$Result = Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/run" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $RunBody

$Result.status
$Result.jobId
$Result.evidence.screenshots

Passo 6: Leia o resultado

Campos importantes:

  • status: passed ou failed.
  • jobId: nome da pasta de artefatos.
  • failedStepIndex: índice do passo que falhou, quando houver falha.
  • error: erro de alto nível em caso de falha.
  • steps: status e tempos de cada passo.
  • extracted: valores salvos pelos passos extract/evaluate/watch.
  • evidence: dados de diagnóstico.

Passo 7: Inspecione os artefatos

Com o Docker Compose, os artefatos são gravados em:

D:\WorkSpace\ScrapForAI\artifacts

Para o job job_abc123, inspecione:

artifacts/job_abc123/result.json
artifacts/job_abc123/screenshots/failure.png
artifacts/job_abc123/trace.zip

O trace só existe quando options.trace é verdadeiro. Veja Artefatos e evidências para o layout completo.

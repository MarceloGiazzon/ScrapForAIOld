Esquemas JSON

O ScrapForAI publica JSON Schemas dinâmicos para requisições e resultados, além dos snapshots de schema versionados no repositório.

Schemas dinâmicos

Invoke-RestMethod -Method Get -Uri "http://localhost:3000/v1/schema"
Invoke-RestMethod -Method Get -Uri "http://localhost:3000/v1/schema/routine.request.json"
Invoke-RestMethod -Method Get -Uri "http://localhost:3000/v1/schema/routine.result.json"

Schemas versionados

schema/routine.request.json
schema/routine.result.json

Para regerá-los:

npm run generate:schema

O build também regenera os schemas primeiro:

npm run build

O schema dinâmico reflete os limites do ambiente em execução. O schema versionado reflete os padrões no momento da geração.

Regras de validação entre campos

A validação no servidor também aplica regras entre campos que não são totalmente capturadas pelo JSON Schema, incluindo:

  • IDs de passo únicos.
  • waitForElapsed.sinceStepId deve apontar para um passo anterior.
  • Exatamente uma fonte de valor para passos baseados em valor.
  • Exatamente uma condição de espera em waitFor e afterWaitFor.
  • evaluate e watch exigem ALLOW_EVALUATE=true.

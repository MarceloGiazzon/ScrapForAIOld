Referência da API

Todos os endpoints HTTP expostos pelo ScrapForAI, seus requisitos de autenticação, formatos de requisição e códigos de status.

Autenticação da API

Chamadas protegidas da API exigem um token bearer.

Configuração do cabeçalho no PowerShell:

$ApiKey = "paste-your-scrapforai-api-key-here"
$Headers = @{ Authorization = "Bearer $ApiKey" }

Configuração do cabeçalho com curl:

API_KEY="paste-your-scrapforai-api-key-here"
curl -H "Authorization: Bearer $API_KEY" http://localhost:3000/v1/schema

O endpoint de schema é público, mas usar o mesmo estilo de cabeçalho em todas as chamadas é conveniente.

Comportamento esperado quando não autorizado:

  • Cabeçalho ausente: 401 Unauthorized.
  • Chave de API incorreta: 401 Unauthorized.
  • Endpoint protegido sem token bearer: 401 Unauthorized.

POST /v1/explorations/run

POSTrequer autenticação

Executa uma rotina de exploração de navegador.

$Body = @{
    scenarioName = "basic page check"
    targetUrl = "https://dev.example.com"
    options = @{
        trace = $false
        screenshots = "onFailure"
        collectDomOnFailure = $true
    }
    steps = @(
        @{ action = "goto"; url = "`$targetUrl" },
        @{ action = "assertTextContains"; selector = "body"; text = "Welcome" },
        @{ action = "collect"; what = @("console", "network", "url") }
    )
} | ConvertTo-Json -Depth 20

Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/run" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $Body
StatusSignificado
200A rotina foi executada e passou.
500Uma rotina válida foi executada, mas falhou (ex.: uma asserção de passo ou timeout).
400A requisição é inválida, ou uma URL não é permitida.
401A autenticação falhou.
429Já existem muitos jobs em execução (veja MAX_PARALLEL_JOBS).

POST /v1/explorations/inspect-dom

POSTrequer autenticação

Inspeciona a página de destino e retorna controles, formulários, seletores, texto e evidências diagnósticas opcionais.

$Body = @{
    targetUrl = "https://dev.example.com/login"
    waitUntil = "domcontentloaded"
    includeRenderedHtml = $false
    includeHiddenControls = $true
    includeConsole = $true
    includeNetwork = $false
    redactSensitiveValues = $true
} | ConvertTo-Json -Depth 20

Invoke-RestMethod `
    -Method Post `
    -Uri "http://localhost:3000/v1/explorations/inspect-dom" `
    -Headers $Headers `
    -ContentType "application/json" `
    -Body $Body

Veja o guia de inspeção de DOM para o formato completo da resposta e referência de campos.

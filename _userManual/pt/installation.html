Instalação e configuração

Duas formas suportadas de executar o ScrapForAI: Docker Compose para uso normal, ou Node.js local para desenvolvimento. A configuração é baseada em variáveis de ambiente em ambos os casos.

Pré-requisitos

Runtime recomendado:

  • Docker Desktop.
  • Doppler CLI para gerenciamento de segredos.
  • Node.js LTS para desenvolvimento local fora do Docker.
  • npm.

Opcional:

  • Cloudflare cloudflared, se você quiser um túnel de desenvolvimento temporário. O arquivo Docker Compose pode executar o cloudflared para você através do perfil tunnel.

Opção 1: Instalação com Docker Compose

Recomendado para uso normal.

  1. Abra o PowerShell.
  2. Vá para a pasta do projeto: 
    Set-Location -Path "D:\WorkSpace\ScrapForAI"
  3. Instale e configure o Doppler: 
    doppler login
doppler setup
  4. Compile e inicie a API: 
    doppler run -- docker compose up --build
  5. Verifique a saúde do serviço: 
    Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Resposta esperada:

{
  "status": "ok",
  "service": "ScrapForAI",
  "time": "2026-06-12T00:00:00.000Z"
}

Opção 2: Instalação local com Node.js

Útil para desenvolvimento.

  1. Abra o PowerShell.
  2. Vá para a pasta do projeto: 
    Set-Location -Path "D:\WorkSpace\ScrapForAI"
  3. Instale as dependências: 
    npm ci
  4. Crie um arquivo .env local a partir de .env.example e edite os valores: 
    Copy-Item .env.example .env
  5. Instale as dependências do navegador do Playwright, se necessário: 
    npx playwright install
  6. Inicie o servidor de desenvolvimento: 
    npm run dev
  7. Em outra janela do PowerShell, verifique a saúde do serviço: 
    Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

Configuração

O ScrapForAI lê a configuração a partir de variáveis de ambiente. No Docker Compose, elas são passadas para o container. No desenvolvimento local, o .env é carregado pela aplicação.

Variáveis obrigatórias

VariávelObrigatóriaExemploFinalidade
SCRAPFORAI_API_KEYSimuse-a-long-random-secretToken bearer obrigatório para endpoints protegidos. Deve ter no mínimo 16 caracteres.
ALLOWED_TARGET_ORIGINSSimhttps://dev.example.com,https://qa.example.comOrigens que o ScrapForAI pode visitar como URLs de destino e redirecionamentos do frame principal. Deve conter ao menos uma origem.

Variáveis comuns do servidor

VariávelPadrãoFinalidade
NODE_ENVdevelopmentModo de execução: development, test ou production.
PORT3000Porta HTTP dentro da aplicação/container.
HOST0.0.0.0Interface de rede a ser vinculada.
LOG_LEVELinfoNível de log do Pino.
MAX_REQUEST_BODY_SIZE1mbTamanho máximo de requisição JSON aceito pelo Express.
CORS_ALLOWED_ORIGINSlista vaziaOrigens de navegador permitidas pelo CORS. Clientes que não são navegadores não são afetados.

Limites de navegador e job

VariávelPadrãoFinalidade
PLAYWRIGHT_BROWSERchromiumMotor do navegador: chromium, firefox ou webkit.
MAX_STEPS_PER_JOB50Número máximo de passos em uma rotina.
MAX_PARALLEL_JOBS2Número máximo de jobs de exploração ou inspeção em paralelo.
JOB_TIMEOUT_MS60000Timeout total de uma rotina.
STEP_TIMEOUT_MS10000Timeout máximo para a maioria das ações de passo.
MAX_DOM_SNAPSHOT_CHARS20000Tamanho máximo do snapshot de texto do DOM ou HTML renderizado.

Limites de evaluate e watch

VariávelPadrãoFinalidade
ALLOW_EVALUATEfalseHabilita os passos evaluate e watch quando verdadeiro.
MAX_EVALUATE_SCRIPT_CHARS4000Tamanho máximo do script JavaScript.
MAX_EVALUATE_RESULT_CHARS20000Tamanho máximo do resultado serializado antes de truncar.
EVALUATE_TIMEOUT_MS5000Timeout para uma avaliação de script.
MAX_WATCH_DURATION_MS30000Duração máxima do watch.
MIN_WATCH_INTERVAL_MS100Intervalo mínimo de amostragem do watch.
MAX_WATCH_SAMPLES200Número máximo de amostras do watch.

Variáveis de artefatos

VariávelPadrãoFinalidade
ARTIFACT_DIR/app/artifactsDiretório onde os artefatos do job são salvos. No Compose, isso mapeia para ./artifacts.
ARTIFACT_RETENTION_HOURS4Pastas de artefatos mais antigas que isso são removidas quando novos jobs criam um repositório de artefatos.

Exemplo de .env

NODE_ENV=development
PORT=3000
HOST=0.0.0.0

SCRAPFORAI_API_KEY=replace-with-a-strong-random-value

ALLOWED_TARGET_ORIGINS=https://dev.example.com,https://qa.example.com
ALLOWED_RESOURCE_ORIGINS=https://dev.example.com,https://qa.example.com,https://api-dev.example.com
CORS_ALLOWED_ORIGINS=http://localhost:3000

MAX_STEPS_PER_JOB=50
JOB_TIMEOUT_MS=60000
STEP_TIMEOUT_MS=10000
MAX_REQUEST_BODY_SIZE=1mb
MAX_PARALLEL_JOBS=2
MAX_DOM_SNAPSHOT_CHARS=20000

ALLOW_EVALUATE=false
MAX_EVALUATE_SCRIPT_CHARS=4000
MAX_EVALUATE_RESULT_CHARS=20000
EVALUATE_TIMEOUT_MS=5000
MAX_WATCH_DURATION_MS=30000
MIN_WATCH_INTERVAL_MS=100
MAX_WATCH_SAMPLES=200

ARTIFACT_RETENTION_HOURS=4
ARTIFACT_DIR=/app/artifacts
LOG_LEVEL=info
PLAYWRIGHT_BROWSER=chromium

Executando o ScrapForAI

Iniciar com Docker Compose

Set-Location -Path "D:\WorkSpace\ScrapForAI"
doppler run -- docker compose up --build

O arquivo Compose vincula a API a http://localhost:3000. O mapeamento de host é restrito a 127.0.0.1:3000:3000, então o serviço é exposto localmente por padrão.

Iniciar para desenvolvimento local

Set-Location -Path "D:\WorkSpace\ScrapForAI"
npm run dev

Iniciar código de produção compilado localmente

Set-Location -Path "D:\WorkSpace\ScrapForAI"
npm run build
npm start

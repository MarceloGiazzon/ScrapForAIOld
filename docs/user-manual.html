ScrapForAI User Manual

Product version: 1.0.0
Manual version: 1.0
Last updated: 2026-06-14

What ScrapForAI is

ScrapForAI is a security-first browser exploration runner for controlled development and test websites. It exposes an HTTP API that accepts a restricted JSON routine, opens a browser with Playwright, performs the requested steps, collects useful evidence, redacts known secrets, and returns a structured result that an AI development tool or automation client can consume.

Use it when you need an automated agent to inspect, click through, validate, or collect evidence from a web application in a predictable and controlled way.

  • Open development or QA URLs.
  • Fill forms with disposable test credentials.
  • Click menus, buttons, links, tabs, and form controls.
  • Wait for page loads, selectors, URLs, or network responses.
  • Assert text, visibility, enabled state, counts, or URL conditions.
  • Collect screenshots, console logs, network evidence, DOM text, and page errors.
  • Inspect DOM controls and selectors before building a routine.

What ScrapForAI is not

ScrapForAI is not a generic open-web scraper. It intentionally avoids anti-bot evasion, CAPTCHA bypassing, stored browser sessions, credential vaulting, site-specific scraping logic, unlimited JavaScript execution, and arbitrary navigation.

Use ScrapForAI only against systems you control or have permission to test. Avoid production data unless you have a specific, approved, controlled reason.

Who should use ScrapForAI

  • Developers who want an AI assistant to reproduce UI bugs in local, dev, or QA environments.
  • QA engineers who need repeatable browser smoke checks with structured evidence.
  • Platform engineers who want a browser runner with explicit security boundaries.
  • AI tool builders who need a controlled API for web app inspection and interaction.
  • Support engineers who need reproducible evidence from test systems.

Core concepts

Routine

A routine is the JSON request sent to POST /v1/explorations/run. It contains a targetUrl, optional metadata, optional credentials and variables, runtime options, and ordered steps.

Step

A step is one browser action or assertion. Steps run in order. When a step fails, the routine stops and returns status: "failed".

Evidence

Evidence is diagnostic data collected while the routine runs: screenshots, traces, console messages, page errors, network events, DOM text snapshots, and the final URL.

Artifact

An artifact is a file written to the artifact directory, such as result.json, screenshots/*.png, or trace.zip.

Allowlist

An allowlist is a configured list of origins ScrapForAI is allowed to visit or expect. ALLOWED_TARGET_ORIGINS controls target URLs and main-frame redirects.

Architecture overview

ScrapForAI is a Node.js and TypeScript service using Express, Playwright, Zod, Pino, Helmet, CORS, rate limiting, and bearer-token authentication.

  1. A client sends a JSON request.
  2. Express authenticates the request unless it is a public endpoint.
  3. Zod validates the request and cross-field rules.
  4. The target URL is checked against ALLOWED_TARGET_ORIGINS.
  5. Playwright opens a browser context.
  6. Steps run in order.
  7. Evidence collectors record diagnostics.
  8. Known secrets are redacted.
  9. A structured JSON result is returned and saved as an artifact.

Security model

Public endpoints

  • GET /health
  • GET /v1/schema
  • GET /v1/schema/routine.request.json
  • GET /v1/schema/routine.result.json

Protected endpoints

  • POST /v1/explorations/run
  • POST /v1/explorations/inspect-dom
Authorization: Bearer <SCRAPFORAI_API_KEY>

Target origin restrictions

ALLOWED_TARGET_ORIGINS controls the initial targetUrl, literal URLs used by goto steps, and main-frame redirects.

ALLOWED_TARGET_ORIGINS=https://dev.example.com,https://qa.example.com

Secret redaction

ScrapForAI redacts the API key, credential values, sensitive recursive keys, and authorization or cookie headers in logs. Put passwords and tokens in credentials, not variables.

JavaScript execution

evaluate and watch execute caller-provided JavaScript inside the page. They are disabled by default.

ALLOW_EVALUATE=false
Enable ALLOW_EVALUATE=true only for trusted local use against controlled development or test origins.

API authentication

Protected API calls require a bearer token.

$ApiKey = "paste-your-scrapforai-api-key-here"
$Headers = @{ Authorization = "Bearer $ApiKey" }

Expected unauthorized behavior: missing or wrong API keys return 401 Unauthorized.

Endpoint reference

GET /health

Checks whether the service is running. Authentication is not required.

Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

GET /v1/schema

Returns links to public JSON schemas.

Invoke-RestMethod -Method Get -Uri "http://localhost:3000/v1/schema"

POST /v1/explorations/run

Runs a browser exploration routine. Authentication is required.

$Body = @{
    scenarioName = "basic page check"
    targetUrl = "https://dev.example.com"
    options = @{
        trace = $false
        screenshots = "onFailure"
        collectDomOnFailure = $true
    }
    steps = @(
        @{ action = "goto"; url = "`$targetUrl" },
        @{ action = "assertTextContains"; selector = "body"; text = "Welcome" },
        @{ action = "collect"; what = @("console", "network", "url") }
    )
} | ConvertTo-Json -Depth 20

Invoke-RestMethod -Method Post -Uri "http://localhost:3000/v1/explorations/run" -Headers $Headers -ContentType "application/json" -Body $Body

POST /v1/explorations/inspect-dom

Inspects a target page and returns controls, forms, selectors, text, and optional diagnostics. Authentication is required.

$Body = @{
    targetUrl = "https://dev.example.com/login"
    waitUntil = "domcontentloaded"
    includeRenderedHtml = $false
    includeHiddenControls = $true
    includeConsole = $true
    includeNetwork = $false
    redactSensitiveValues = $true
} | ConvertTo-Json -Depth 20

Invoke-RestMethod -Method Post -Uri "http://localhost:3000/v1/explorations/inspect-dom" -Headers $Headers -ContentType "application/json" -Body $Body

Routine request guide

Minimal routine

{
  "targetUrl": "https://dev.example.com",
  "steps": [
    {
      "action": "goto",
      "url": "$targetUrl"
    }
  ]
}

Top-level fields

FieldRequiredDescription
scenarioNameNoHuman-readable routine name.
targetUrlYesInitial target URL. Must match ALLOWED_TARGET_ORIGINS.
credentialsNoSecret values used by steps and redacted from results.
variablesNoNon-secret reusable values.
callerNoOptional metadata about the caller.
optionsNoRuntime options.
stepsYesOrdered list of browser actions and assertions.

Options

OptionDefaultDescription
headlesstrueRuns browser without UI.
tracefalseSaves a Playwright trace ZIP.
screenshotsonFailureoff, onFailure, or always.
collectDomOnFailurefalseCaptures DOM text when a step fails.

Common step fields

FieldDescription
idUnique step ID for references like waitForElapsed.
labelShort human-readable label.
descriptionLonger description.
frameTargets an iframe by name, URL fragment, or index.
delayMsWaits before the step action.
waitForWait condition before the action.
afterWaitForWait condition after the action. Response waits are armed before the action.

ActionPurposeKey fields

checkCheck a checkbox or radio.selector

Value sources

fill and selectOption require exactly one of value, valueFromCredential, or valueFromVariable.

{ "action": "fill", "selector": "#password", "valueFromCredential": "loginPassword" }

Wait conditions

waitFor and afterWaitFor support exactly one of selector, response, loadState, or urlContains.

{
  "action": "click",
  "selector": "#submit",
  "afterWaitFor": {
    "response": {
      "urlContains": "/api/save",
      "status": 200
    },
    "timeoutMs": 10000
  }
}

Step-by-step first run

1. Confirm the service is up

Invoke-RestMethod -Method Get -Uri "http://localhost:3000/health"

2. Set your API key header

$ApiKey = "paste-your-scrapforai-api-key-here"
$Headers = @{ Authorization = "Bearer $ApiKey" }

3. Inspect the login page

$InspectBody = @{
    targetUrl = "https://dev.example.com/login"
    includeHiddenControls = $true
    includeConsole = $true
    includeNetwork = $false
    redactSensitiveValues = $true
} | ConvertTo-Json -Depth 20

$Inspection = Invoke-RestMethod -Method Post -Uri "http://localhost:3000/v1/explorations/inspect-dom" -Headers $Headers -ContentType "application/json" -Body $InspectBody
$Inspection.visibleControls | Select-Object index, tag, id, name, type, text, labelContext

4. Run a login routine

$RunBody = @{
    scenarioName = "first login smoke"
    targetUrl = "https://dev.example.com/login"
    credentials = @{
        loginUser = "test-user"
        loginPassword = "test-password"
    }
    options = @{
        trace = $false
        screenshots = "onFailure"
        collectDomOnFailure = $true
    }
    steps = @(
        @{ label = "open login"; action = "goto"; url = "`$targetUrl" },
        @{ label = "fill user"; action = "fill"; selector = "#username"; valueFromCredential = "loginUser" },
        @{ label = "fill password"; action = "fill"; selector = "#password"; valueFromCredential = "loginPassword" },
        @{ label = "submit"; action = "click"; selector = "button[type='submit']"; afterWaitFor = @{ urlContains = "/dashboard"; timeoutMs = 10000 } },
        @{ label = "assert dashboard"; action = "assertTextContains"; selector = "body"; text = "Dashboard" },
        @{ label = "collect diagnostics"; action = "collect"; what = @("console", "network", "url", "pageErrors") }
    )
} | ConvertTo-Json -Depth 30

$Result = Invoke-RestMethod -Method Post -Uri "http://localhost:3000/v1/explorations/run" -Headers $Headers -ContentType "application/json" -Body $RunBody
$Result.status
$Result.jobId

Practical examples

Login smoke test

$Body = @{
    scenarioName = "login smoke test"
    targetUrl = "https://dev.example.com/login"
    options = @{ trace = $false; screenshots = "onFailure"; collectDomOnFailure = $true }
    credentials = @{ loginUser = "test-user"; loginPassword = "test-password" }
    steps = @(
        @{ label = "open app"; action = "goto"; url = "`$targetUrl" },
        @{ label = "fill user"; action = "fill"; selector = "#username"; valueFromCredential = "loginUser" },
        @{ label = "fill password"; action = "fill"; selector = "#password"; valueFromCredential = "loginPassword" },
        @{ label = "submit"; action = "click"; selector = "button[type='submit']" },
        @{ label = "wait for shell"; action = "waitForLoadState"; state = "networkidle"; timeoutMs = 10000 },
        @{ label = "assert text"; action = "assertTextContains"; selector = "body"; text = "Dashboard" }
    )
} | ConvertTo-Json -Depth 20

Form validation

$Body = @{
    scenarioName = "form validation"
    targetUrl = "https://dev.example.com/form"
    variables = @{ invalidValue = "not-valid" }
    steps = @(
        @{ action = "goto"; url = "`$targetUrl" },
        @{ action = "fill"; selector = "[name='email']"; valueFromVariable = "invalidValue" },
        @{ action = "click"; selector = "button[type='submit']" },
        @{ action = "assertTextContains"; selector = "body"; text = "invalid" },
        @{ action = "screenshot"; name = "validation-message" }
    )
} | ConvertTo-Json -Depth 20

Search and data loading

$Body = @{
    scenarioName = "data loading check"
    targetUrl = "https://dev.example.com/search"
    variables = @{ searchText = "ABC123" }
    steps = @(
        @{ action = "goto"; url = "`$targetUrl" },
        @{ action = "fill"; selector = "[name='search']"; valueFromVariable = "searchText" },
        @{ action = "press"; selector = "[name='search']"; key = "Enter" },
        @{ action = "waitForResponse"; urlContains = "/api/search"; method = "GET"; status = 200 },
        @{ action = "waitForSelector"; selector = "[data-row]"; state = "visible" },
        @{ action = "extractText"; selector = "[data-row]"; name = "firstRowText" }
    )
} | ConvertTo-Json -Depth 20

Evaluate page state, trusted local only

$Body = @{
    scenarioName = "cart state debug"
    targetUrl = "https://dev.example.com/cart"
    steps = @(
        @{ action = "goto"; url = "`$targetUrl" },
        @{ action = "evaluate"; name = "cartSummary"; script = "return { itemCount: document.querySelectorAll('[data-cart-item]').length, url: location.href };" }
    )
} | ConvertTo-Json -Depth 20
The evaluate example requires ALLOW_EVALUATE=true and should be used only in trusted local testing.

Selector selection advice

  1. Prefer unique IDs.
  2. Use data-testid when available.
  3. Use named input selectors such as input[name="email"].
  4. Avoid generated class names and deep layout selectors.

Troubleshooting

Health endpoint fails

  • Confirm the container or dev server is running.
  • Check whether port 3000 is already in use.
  • Inspect logs with docker logs scrapforai-api.

Protected endpoint returns 401

  • Check header format: Authorization: Bearer <key>.
  • Confirm the key matches SCRAPFORAI_API_KEY.
  • Confirm the key is at least 16 characters.

Request returns 400 ValidationError

  • Check required fields.
  • Check step action names.
  • Use exactly one value source for value-based steps.
  • Use exactly one wait condition in waitFor or afterWaitFor.

URL is rejected

  • Confirm the origin is in ALLOWED_TARGET_ORIGINS.
  • Check scheme and port.
  • Confirm redirects stay on allowed origins.

Step times out

  • Inspect DOM to find a better selector.
  • Use frame for iframe content.
  • Add a more precise waitFor or afterWaitFor.
  • Increase timeout values when the environment is slow.

waitForResponse misses a response

Use afterWaitFor.response on the action that triggers the response, so the listener is armed before the action.

Operational checklist

Before connecting an AI tool

  • Set a strong SCRAPFORAI_API_KEY.
  • Keep ALLOWED_TARGET_ORIGINS narrow.
  • Keep ALLOWED_RESOURCE_ORIGINS explicit.
  • Keep ALLOW_EVALUATE=false unless trusted local testing requires it.
  • Use disposable test credentials.
  • Keep artifact retention short.
  • Verify auth rejection, allowlist rejection, and invalid JSON rejection.

Before sharing artifacts

  • Review screenshots.
  • Review result.json.
  • Review trace contents.
  • Confirm credentials and tokens are redacted.
